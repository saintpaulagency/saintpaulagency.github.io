How the addresses work. Each link reads who it's for / what it is, for example saintpaulagency.github.io/leadership/borton-volvo-google-ads/. They forward to where each page lives, so older links keep working too.

Passwords. Both live in the SPA Dashboards group in the Passwords app. “SPA dashboards” opens this page and every card marked “SPA Dashboards password”. “Meta time saver” opens only the Meta Time Saver. One page keeps its own report password on purpose: the CDF Microsoft page, which is made to share with Microsoft Advertising. Cards marked “No password” are for clients and prospects. A device that unlocked one of these pages in the last 7 days opens the others straight away. Never paste a password into a chat or an email; share the group instead.

The repos are public so GitHub can host them, which means folder names can be seen. Every page with client numbers stays locked until the password is entered.
